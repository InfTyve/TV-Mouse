# TV Mouse

[简体中文](./README.md) | [English](./README.en.md)

Control the mouse pointer on Android TV with a remote, and operate other apps just like a mouse.

## Features

- Floating mouse pointer: move with the arrow keys, click with the OK key, and long-press with a long press of the OK key.
- After enabling "Fixed Sliding" in settings, you can control interface sliding.
- Supports customizable pointer appearance: includes a default appearance, and you can also import images and save them as new appearances.
- Supports Chinese and English interfaces: follows the system language by default, and can also be switched manually.

## Usage

Open the app's main interface, grant overlay permission and accessibility service permission, and then you can enable the mouse function.

After enabling it, use the remote's arrow keys to move the pointer, press the OK key to click, and long-press the OK key to perform a long-press action.

Long-press the Back key for 3 seconds to open settings, or you can directly enter custom appearance or language settings from the app's main interface.

Use the Volume Up and Menu keys to enable "Fixed Sliding" to control interface sliding. After enabling it, long-press the Back key for 3 seconds to turn it off.

In the app's main interface or settings, you can hide or turn off the mouse pointer. Set the language and customize the appearance.

## Custom Appearance

In the "Custom Appearance" option in settings, import a `128 × 128` pixel PNG or JPG image. A PNG with a transparent background is recommended.

After entering a name and saving it, you can switch to and use it in the appearance list.

## Compatibility

Supports Android 4.4 (API 19) to Android 15 (API 35)
